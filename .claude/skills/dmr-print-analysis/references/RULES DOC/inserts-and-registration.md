Inserts classification
1 – FOLD/GATEFOLD (or BATTENTE in Italian)
There are two kinds of GATEFOLDS:
1A – GATEFOLD ON C1 (OFC): Thick pages connected to the Outside Front Cover; usually 2 pages but sometimes 3 pages (1 cut in 2 half pages + 1 full page – Fig. 3) or more.
ISSUE MANAGER
In the Issue manager, in the insert manager sub-form, create a new insert as follows:
Page number: C1b1/b2 (Fig. 1 and 2), C1b1-b3 (Fig. 3)Type: FOLD/GATEFOLD Format: 1XTotal pages: 2 (Fig. 1 and 2) or 3 (Fig. 3)Brand’s nameIn the notes please mark any non-standard element (for example WINDOW, TRANSPARENT PAPER, etc.)
SCANNING
Scan all the pages following the order in which they appear when the folder is OPEN. This means that Reverse gatefolds come BEFORE the front cover jpg.In case of Folder Window (Fig. 3), the two halves of the cover must be merged in one single image while the two halves of the advertising must be kept apart in order to have a total of 3 pages for the folder.
DATA TRACKING
In the Insert sub-form of the data entry program create a GATEFOLD insert, 2 pages (or 3 pages for Fig. 3), format 1X (if some of the pages are smaller than 1x, when registering the data, put the correct size for these pages).
Structure of page numbers: cover (OFC) + b for battente + progressive number
C1b1/b2 (DOUBLE PAGE) – VALUE: 2FP(Fig. 1) 
C1b1 (RH – SINGLE PAGE) – VALUE: 1FP  (Fig. 2)C1b2 (LH – SINGLE PAGE) – VALUE: 1FP
C1b1 (LH – SINGLE PAGE) – VALUE: 1 HP  (Fig. 3)C1b2 (RH – SINGLE PAGE) – VALUE: 1 FPC1b3 (RH –SINGLE PAGE) – VALUE: 1 HP
1B– GATEFOLD ON C2 (IFC): Thick pages connected to the Inside Front Cover; usually 4 pages but sometimes 3 because the 4th one is an editorial page. Please note that the 4th page is usually in thin paper.
ISSUE MANAGER
In the Issue manager, in the insert manager sub-form, create a new insert as follows:
Page number: C2b1/b3Type:  FOLD/GATEFOLDFormat: 1XTotal pages: 3 (for example) Brand’s nameIn the notes please mark any non-standard element (for example WINDOW, TRANSPARENT PAPER, etc.) 
SCANNING
Scan all the pages following the order in which they appear when the folder is open. 
DATA TRACKING
In the Insert sub-form of the data entry program create a GATEFOLD insert, 3 pages, format 1X
Structure of page numbers: cover (IFC) + b for battente + progressive number
C2b1 (RH – SINGLE PAGE) – VALUE: 1FPC2b2/b3 (DOUBLE PAGE) – VALUE: 2FP

3 – LOOSE INSERTS (LC)
This typology includes all the inserts that have no other bond with the magazine but the wrapping. They can be found in the same or separate pocket of the wrapping of the main magazine or between the pages of the main book. They are considered as one single page, even if they are composed of several pages.
The more common LOOSE INSERTS are:
LOOSE INSERT – PAGE (typically a single-faced flyer) LOOSE INSERT – BOOKLET (a catalogue of a brand or shopping mall) LOOSE INSERT – FOLDER (a folded multi-pages flyer) LOOSE INSERT – POSTCARD/DIE CUTTING/CARD (not the magazine’s subscription card)LOOSE INSERT – OVER THE COVER
LOOSE INSERT - POSTER
